# NYC Flights 2013 Analysis

This project explores the `nycflights13` dataset using R and the tidyverse. The analysis covers flight delays, cancellations, weather impacts, and seasonal trends.

## Contents
- `Group7_FinalProject_RedSquadron_v002.Rmd`: Main R Markdown report
- `data/`: Source or derived data (if used)
- `output/`: Final visualizations or reports

## How to Run
1. Open the `.Rmd` file in RStudio.
2. Knit to HTML or PDF.
3. Ensure `nycflights13`, `tidyverse`, `lubridate`, etc. are installed.
